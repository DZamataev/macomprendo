# `Character Body 2D`), engine concepts come back mis-cased (`Autoload` -> `AutoLoad`),
# and snake_case methods come back as two words (`queue_free` -> `queue free`). `Godot`
# itself is absent because the model writes it correctly, and so are API calls nobody
# dictates, such as `Input.parse_input_event`.
