# Human and computer app icon

Approved design: a cool blue robotic left hand and warm peach human right hand
form a heart in negative space on a midnight-blue rounded tile. Keep the approved
composition and gentle dimensional style, with transparent exterior padding.

The master is `macos/AppBundle/AppIcon.png`. `npm run icon` derives the standard
16–1024 pixel macOS representations and writes `AppIcon.icns`. The existing bundle
resource reference is retained. The menubar template symbol remains separate.

Implementation: store the production master, add an atomic icon compiler using
macOS sips/iconutil, update the npm command and changelog, verify icon resources,
run repository checks, then install and launch the Developer ID signed local build.
